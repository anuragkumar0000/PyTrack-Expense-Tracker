# PyTrack - Personal Expense Tracker

PyTrack is a Python-based personal expense tracker that helps users manage their income and daily expenses.

## Features

- Add income
- Add expenses
- Store expense category and notes
- Calculate total expenses
- Calculate remaining balance
- Input validation
- JSON-based data storage

## Technologies Used

- Python
- JSON
- File Handling
- Functions
- Exception Handling

## How to Run

1. Download or clone this repository.
2. Open `pytrack_v2.py`.
3. Run the Python program.
4. Follow the menu options shown on the screen.

## Project Structure

- `main.py` - PyTrack Version 1
- `pytrack_v2.py` - PyTrack Version 2 with income and balance tracking
- `expenses.json` - Expense data generated when the program runs
- `income.json` - Income data generated when the program runs
